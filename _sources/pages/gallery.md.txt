## Software Projects

<div class="grid cards" markdown>

-   ![Bluesky Ecosystem](../_static/gallery/bluesky-overview.png){ .card-image }

    <hr>

    **[Bluesky Ecosystem](https://blueskyproject.io)**

    Architecture overview of the Bluesky experiment orchestration ecosystem: run engine, ophyd device layer, databroker, and associated tools developed at NSLS-II. See [blueskyproject.io](https://blueskyproject.io) and [Allan et al., Synchrotron Radiat. News **32**, 19 (2019)](https://doi.org/10.1080/08940886.2019.1608121).

    <span class="cv-date">Nov 2017 – present</span>

-   ![Autonomous Beamline Alignment (BLOP)](../_static/gallery/TES-blop.jpg){ .card-image }

    <hr>

    **[Autonomous Beamline Alignment (BLOP)](https://doi.org/10.1107/S1600577524008993)**

    Four beam configurations on the NSLS-II TES (8-BM) beamline: upper-left shows the initial beam; lower-right shows the optimal alignment. Six degrees of freedom (KB mirror translations/rotations and toroidal mirror pitch/translation) are tuned to maximize flux density. From [Morris et al., J. Synchrotron Rad. **31**, 1446 (2024)](https://doi.org/10.1107/S1600577524008993).

    <span class="cv-date">2020 – present</span>

-   ![Sirepo](../_static/gallery/Sirepo.jpg){ .card-image }

    <hr>

    **[Sirepo](https://www.sirepo.com)**

    Sirepo — a cloud-based web interface for X-ray source and optics simulations powered by SRW, developed at RadiaSoft / NSLS-II. Enables browser-based setup, execution, and visualization of synchrotron beamline simulations. See [Rakitin et al., J. Synchrotron Rad. **25**, 1877 (2018)](https://doi.org/10.1107/S1600577518010986).

    <span class="cv-date">Dec 2015 – present</span>

-   ![TkInter GUI for SRW](../_static/gallery/SRW-gui.png){ .card-image }

    <hr>

    **[TkInter GUI for SRW](https://github.com/mrakitin/SRW-gui)**

    Prototype desktop GUI for Synchrotron Radiation Workshop (SRW), developed as a job-interview demo at BNL.

    <span class="cv-date">Jul 2015</span>

-   ![Stokes Random-Cell Generator API](../_static/gallery/USPEX-api.png){ .card-image }

    <hr>

    **[Stokes Random-Cell Generator API](https://uspex.stonybrook.edu)**

    Simplified REST API for on-the-fly generation of random crystal cells, part of USPEX online utilities at Stony Brook University.

    <span class="cv-date">Jun 2015</span>
