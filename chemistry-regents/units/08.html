Unit 08: Oxidation-Reduction

⏱50–65 min 📊★★★ Challenging 🔗Requires: Unit 02, Unit 04

Key Concepts

OIL RIG

OIL = Oxidation Is Loss (of electrons)  |  RIG = Reduction Is Gain (of electrons)

RoleProcessOxidation # change
Reducing agentIs oxidized (loses e⁻)Increases
Oxidizing agentIs reduced (gains e⁻)Decreases

Oxidation Number Rules

  • Pure elements = 0 (e.g., Fe, O₂, Na)
  • Monatomic ions = ion charge (Na⁺ = +1, Cl⁻ = −1)
  • O in compounds = −2 (except peroxides: −1)
  • H in compounds = +1 (except metal hydrides: −1)
  • F always = −1
  • Sum = 0 for neutral compounds; sum = ion charge for polyatomic ions

Electrochemical Cells

Galvanic (Voltaic)Electrolytic
Energy conversionChemical → ElectricalElectrical → Chemical
ReactionSpontaneousNon-spontaneous (forced)
AnodeOxidation (negative)Oxidation (positive terminal)
CathodeReduction (positive)Reduction (negative terminal)
Memory: A.O.C.R. — Anode = Oxidation, Cathode = Reduction (in both cell types).
⚠️ Common traps: The reducing agent IS OXIDIZED. The oxidizing agent IS REDUCED. Peroxides (H₂O₂) have O = −1, not −2.

Practice Quiz

Q1. In the reaction Mg + 2HCl → MgCl₂ + H₂, what is oxidized?
Mg: 0 → +2 (increase in oxidation number = oxidized). H: +1 → 0 (reduced).
Q2. The oxidation number of sulfur in SO₄²⁻ is
S + 4(−2) = −2 → S − 8 = −2 → S = +6.
Q3. In a galvanic cell, oxidation occurs at the
In a galvanic cell: anode = oxidation = negative electrode (releases electrons).
Q4. Which metal in Table J is the strongest reducing agent?
Lithium is at the top of the activity series — most active metal → strongest reducing agent.
Q5. The correct half-reaction for reduction of Cu²⁺ is
Reduction = gain of electrons: Cu²⁺ + 2e⁻ → Cu (RIG).
Q6. The purpose of the salt bridge in a galvanic cell is to
The salt bridge allows ions to migrate between half-cells to maintain electrical neutrality without mixing solutions.
Q7. The oxidation number of Mn in KMnO₄ is
+1 + Mn + 4(−2) = 0 → Mn − 7 = 0 → Mn = +7.
Q8. Will zinc (Zn) spontaneously displace copper (Cu) from CuSO₄ solution?
Table J: Zn is above Cu → more active → Zn displaces Cu²⁺ spontaneously.
Q9. The oxidation number of Fe in Fe₂O₃ is
2Fe + 3(−2) = 0 → 2Fe = +6 → Fe = +3.
Q10. In an electrolytic cell, the energy conversion is
Electrolytic cells use electrical energy to force a non-spontaneous chemical reaction.
