Unit 03: Periodic Table

⏱30–45 min 📊★☆☆ Introductory 🔗Requires: Unit 02

Key Concepts

Organization

FeatureDescription
Period (row)Horizontal; period # = number of occupied energy levels
Group (column)Vertical; same # of valence electrons → similar properties
MetalsLeft/center; shiny, malleable, conductors
NonmetalsUpper right; dull, brittle, poor conductors
MetalloidsOn the staircase: B, Si, Ge, As, Sb, Te, At

Key Groups

GroupNameValence e⁻Properties
1Alkali metals1Very reactive; soft; react with water
2Alkaline earth metals2Reactive metals
17Halogens7Very reactive nonmetals; form salts
18Noble gases8 (He: 2)Unreactive; full valence shell

Periodic Trends

PropertyAcross period (→)Down group (↓)
Atomic radiusDecreases ⬇Increases ⬆
Ionization energyIncreases ⬆Decreases ⬇
ElectronegativityIncreases ⬆Decreases ⬇
Metallic characterDecreases ⬇Increases ⬆
Memory: IE and EN both increase going right and up. Atomic radius increases going left and down. Fluorine has the highest EN (4.0).
⚠️ Common traps: "Period" = horizontal row; "Group" = vertical column. Noble gases have 8 valence e⁻ except He (2). H is in Group 1 but is NOT an alkali metal.

Practice Quiz

0 / 0
Q1. Elements in the same group have similar chemical properties because they have
Same group = same number of valence electrons → similar chemical behavior.
Q2. Which has the largest atomic radius?
All Group 1; atomic radius increases going down → Rb (lowest in list) is largest.
Q3. Which element is a metalloid?
Silicon is a classic metalloid on the staircase between metals and nonmetals.
Q4. Which element has the highest first ionization energy?
Ionization energy increases left → right across a period. Cl is furthest right among these options.
Q5. The most electronegative element is
Fluorine (EN = 4.0) is the most electronegative element on the periodic table.
Q6. An element in Period 3, Group 16 has how many valence electrons?
Group 16 = 6 valence electrons. Period 3 tells us it's in the 3rd energy level.
Q7. Moving down Group 1 (alkali metals), reactivity
Going down → larger atom → valence e⁻ farther from nucleus → easier to lose → more reactive.
Q8. Which pair of elements has the most similar chemical properties?
Na and K are in the same group (Group 1) → same valence electrons → most similar properties.
Q9. As you move across Period 3 from left to right, atomic radius
More protons across a period pull electrons closer → smaller atomic radius.
Q10. Which element would have properties most similar to chlorine (Cl)?
Bromine is in Group 17 (same group as Cl) → same number of valence electrons → most similar properties.
